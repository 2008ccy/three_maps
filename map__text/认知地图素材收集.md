# 认知地图 · 素材收集

## 认知地图到底是什么

作业第六部分原文：

> 认知地图聚焦人工智能与设计中的思考方法、分析案例和持续成长习惯。它应说明：我们怎样理解一个问题，依据什么判断，遇到新证据后怎样调整。

课件第 11 页给了更短的一句：

> 认知地图 = 探索和判断的方法——怎样理解、比较和检验？

两句说的是同一件事。**认知地图不堆知识，它记录「我们是怎么想这件事的」**：用什么方法拆问题、凭什么下判断、发现新证据后怎么改。跟领域地图（学什么）、生态地图（谁在做）分工不同，它回答的是「怎么想清楚、怎么判断对错」。

## 一、三个「观」（课堂认识方法）

作业要求「运用课程讲授的三个观观察所选领域」，重点是把它用到具体问题上。我按课件里反复出现的那条主线，把三个观落成本组的语言模型选题：

| 观       | 问的是什么                            | 用在「语言模型」选题上                                                                           |
| ------- | -------------------------------- | ------------------------------------------------------------------------------------- |
| **系统观** | 整体由哪些环节组成？它们怎样相互影响？瓶颈卡在哪？        | 数据→分词→模型→训练目标→评测→部署是一条链；只换更大的模型、数据脏、评测选错，答疑效果都不会变好。课件第 29 页原话：「用系统观拆开过程，逐步检查问题出在哪一环」。 |
| **发展观** | 一种方法为什么出现？解决了上一阶段的什么难题？又带来什么新限制？ | LoRA 出现，是因为全量微调显存和成本太高；量化流行，是为了塞进更小显存，却引入精度损失。这是「新方法带来新限制」的典型——每个新工具都站在旧工具的代价上。       |
| **求真观** | 凭什么相信一个结论？怎么检验它是真还是幻觉？发现反例后怎么改？  | 训练 loss 降了、榜单分高了，都不等于「回答真的变好」。要打开原文核对、亲自试用、主动找反例，才能避免把流畅的 AI 输出当成正确的理解。               |

> 三个观正好把一件事的三个侧面看全：**结构（系统观）→ 历史（发展观）→ 真伪（求真观）**。课件第 19 页「核心素养」第一项「认知与求真——主动寻找反例，并据此修正判断」、第 24 页「理解的错觉」，都在强调求真观这一层，写进地图时能直接引用。

## 二、分析方法（6 选 2-3，配本组案例）

作业给了 6 种方法，每组选 2-3 种，每种配一个本组实际分析过的例子。案例统一用五步格式：

> 具体问题 → 使用的方法 → 依据与比较 → 当前判断 → 尚存疑问

| 方法      | 在 AI 与设计中的应用例子（作业原文）       |
| ------- | -------------------------- |
| 问题定义    | 用户真正困难的是什么？增加 AI 功能是否能够解决？ |
| 系统拆解    | 失败来自模型、数据、硬件、交互，还是工作流程？    |
| 对照比较    | 两个模型或方案的比较条件是否一致？          |
| 演进分析    | 新方法解决了什么旧问题，又带来什么新限制？      |
| 多目标取舍   | 准确率、速度、成本、体验和安全之间如何选择？     |
| 反例与边界检查 | 什么情况下结论不成立？什么证据可能推翻判断？     |

### 本组选这 3 种（对应选题的三个真问题）

**① 系统拆解 + 反例检查 → 案例「损失下降 ≠ 回答更好」**

- 具体问题：微调时训练 loss 一直降，答疑质量真的变好了吗？
- 使用的方法：系统拆解（把「训练目标」和「最终效果」拆成两环）+ 反例检查（找「loss 降但回答变差」的过拟合反例）。
- 依据与比较：训练 loss 只说明「训练目标这一环」在收敛；过拟合的典型信号是训练曲线降、验证曲线反而升，两者分叉；交叉熵不直接对应「回答有没有用、有没有胡说」。
- 当前判断：下「微调有效」的结论前，至少看训练/验证两条曲线 + 一个下游评测 + 抽几条真实问题人工看，四者同向才敢说变好。
- 尚存疑问：本组实验还没跑完，等真实损失曲线出来再补数据。

**② 对照比较 + 问题定义 → 案例「通用榜单排名 ≠ 适合课程答疑」**

- 具体问题：榜单靠前的模型，就一定适合做本课程的答疑助手吗？
- 使用的方法：问题定义（先问「课程答疑真正要的是什么」）+ 对照比较（比较条件是否一致）。
- 依据与比较：通用 benchmark（MMLU / C-Eval / GSM8K 等）测的是通用能力，还可能有数据污染；课程答疑要的是「本课程术语准确、能顺着思路引导」，通用榜测不出来。
- 当前判断：榜单只做初筛，最终用「本课程自建评测集 + 抽样人工评」来判断。
- 尚存疑问：自建评测集的标准答案和评分标准还没定。

**③ 多目标取舍 + 演进分析 → 案例「效果与成本怎样取舍」**

- 具体问题：模型越大上限越高，但显存、延迟、部署成本也越高，怎么选？
- 使用的方法：多目标取舍（准确率/速度/成本/体验几维怎么权衡）+ 演进分析（量化、参数高效方法为什么出现）。
- 依据与比较：网上有组现成的对比——全参数微调要重训整模型，资源最重；LoRA 只训低秩矩阵，参数省一个量级；RAG 干脆不训模型、外挂检索。华为云有个比喻很贴切：RAG 像租车随用随取、LoRA 像高铁性价比高、全参像自己造车。QLoRA 更进一步，把基础模型 4-bit 量化，7B 模型的显存占用能从约 14GB 压到约 4GB，普通消费级显卡就能微调。本组网站 AI 先走外部 API、训练实验单独排资源，本身就是一次取舍。
- 当前判断：课程答疑对延迟和成本敏感，小模型 + 好数据可能比大模型更划算，待实测。
- 尚存疑问：具体模型和 API 单价还没定，取舍暂无真实数字支撑。

## 三、把成长要求落实为习惯

作业给了 6 类习惯，每组选几项实际执行并留简短例子。本组优先选能直接落地的：

| 习惯     | 本组能做的动作                     |
| ------ | --------------------------- |
| 思维习惯   | 先问问题再选工具；区分事实与推断；主动找反例      |
| 学习习惯   | 任务卡住时反查知识缺口；把「讲不清」标成下周要学的地方 |
| 实践习惯   | 小规模试跑；保留输入输出和失败记录           |
| 管理习惯   | 每周拆任务、明责任人；留来源和版本；卡住早说      |
| 认识更新习惯 | 比较预期 vs 实际，判断该补知识、改方法还是改假设  |
| 协作习惯   | 让没参与的同学先独立用，再听反馈；分歧时摆证据     |

> 课件第 19 页把「核心素养」落到「可观察的行为证据」：认知与求真（主动找反例修正判断）、问题与价值判断（说明为何选此问题、放弃其他）、自主与元学习（识别知识缺口并补足）……作业看的是行为证据，不是口号。这几条正好和上面的习惯一一对应。

## 四、一次真实的认识修正

作业要求展示一次真实的修正，四问：

1. 我们原来以为什么；
2. 哪项资料、尝试或反馈带来了变化；
3. 现在如何理解；
4. 哪些问题仍然不知道。

> 本组有一个现成的好素材：**「认知地图」最初被理解成心理学里的 cognitive map（托尔曼、海马体位置细胞那套），后来读到作业说明第六部分和课件，才发现它是「思考方法地图」，前面按心理学方向找的素材全部作废。** 这就是一次真实的认识修正，可直接用。等真实跑过训练后，再补一个技术层面的修正案例。

## 五、课堂依据速查（第三讲课件可直接引用）

这些是课件原话/出处，写进地图时能证明「用了课堂方法」：

- 认知地图定义（第 11 页）：探索和判断的方法——怎样理解、比较和检验。
- 三图各自核心问题（第 28 页）：认知地图 = 「我怎么把它想清楚？2-3 种思考方法 + 具体案例与成长习惯」。
- 系统观查证法（第 29 页）：拿一段材料问一个能核对的问题，认知地图用「系统观拆开过程，逐步检查问题出在哪一环」。
- 三图练习闭环（第 27 页）：先把问题想清楚（这次要弄明白什么？拿什么判断结果？）→ 让 AI 推进 → 自己检查（打开原文、核对依据、亲自试用）。「讲不清的地方，就是下一步要学的地方。」
- 「理解的错觉」（第 24 页）：Messeri & Crockett, *Nature* 2024（第 627 卷 49–58 页，已被引 1300+ 次）——AI 可能让人高估自己的理解，产出增加、理解反而减少。
- 核心素养 6 项（第 19 页）：认知与求真 / 问题与价值判断 / 自主与元学习 / 创造与探索 / 协作与社会理解 / 伦理与责任，各有可观察的行为证据。
- 知识半衰期（第 14 页）：长半衰期知识做深、短半衰期做快、高阶能力做强——帮我们判断「什么值得长期投入」。
- 判断开放程度（第 43 页）：OSI 开源定义，看「开放了什么」与「允许做什么」——一个现成的「对照比较」范例。
- Token 与价值分开看（第 45 页）：同样一万 token，可能得到有效分析，也可能是一段空话——「消耗量 ≠ 成果价值」。
- 提示词五要素 + 迭代循环（第 48 页）：目标/材料/约束/交付/检查，有目标、有测试、有迭代。
- 提示词六框架（第 50 页）：RTF / CO-STAR / Few-shot / Prompt Chaining / Grounded Prompting / Generate-Review-Refine。
- AI 能力 20 项清单（第 62-65 页）：理解 AI → 委托执行 → 组织工作 → 管理使用，尤其「事实核验与成果验收」「人机分工与责任」两条和认知地图直接相关。

## 六、网上补充素材（可继续深挖）

这些是这次搜集时找到的、能直接撑起案例的公开资料，来源已附上：

- **全参微调 vs LoRA vs RAG 对比**：阿里云开发者社区《3 种大模型微调技术对比：全参、LoRA、RAG》；华为云博客把三种方案比作「租车（RAG，随用随取）／高铁（LoRA，性价比）／自建（全参）」。
- **LoRA 与 QLoRA**：红帽官方科普 LoRA vs QLoRA——QLoRA 在 LoRA 基础上叠了 4-bit 量化，存储占用明显更小。
- **QLoRA 显存数据**：7B 模型显存占用从约 14GB 压到约 4GB，普通消费级显卡即可微调（见 xiaolinnote《大模型微调的方案》）。
- **Messeri & Crockett 论文原文**：*Artificial intelligence and illusions of understanding in scientific research*, *Nature* 2024, 627(8002):49-58（nature.com/articles/s41586-024-07146-0）。
- **OpenAI《异质心智》**（2026-09）：讨论 AI 越来越擅长操控自身推理过程——正好能反衬「求真观」：输出流畅和推理正确是两回事，得靠外部核对。
