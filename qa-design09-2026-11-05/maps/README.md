# 方案 9 · 三张地图界面验收

2026-11-05，针对本地开发预览 `http://127.0.0.1:3000`，使用 Chromium headless、1440×1000 桌面和 390×844 手机视口检查。

- 三图分别检查主题总览、首个主题导读、首个知识点正文、关系图和图节点打开正文，共保存 21 张界面截图。
- 主题卡、筛选、图视图、阅读正文采用统一深墨蓝、暖白文字、金/青/珍珠白点缀及细灰蓝边框。标题、知识状态和来源内容可辨。
- 三图主题和正文弹窗均可通过 Escape 关闭；图中节点可打开相应主题。
- 六个手机弹窗均为 top=0、390×844 的全屏布局，内部正文滚动，上下导航保持可见。关闭按钮均在实际视口内，可见且未被挤出。
- 桌面与手机页面均无页面横向溢出；弹窗内容宽度与弹窗视口相同。
- 没有捕获到浏览器页面异常、控制台错误或 HTTP 400+ 响应。

原始记录：`checks.json`、`dialog-chrome.json`；可复用脚本：`check-maps.mjs`、`check-dialog-chrome.mjs`。截图中左下角 N 标志来自 Next 开发工具，不属于网站正式界面。
