K-QLORAQLoRA在量化冻结基座上训练低秩适配器，节约显存实际训练还需激活、梯度与其他状态S04

K-EVAL评测与数据泄漏用独立题目检查真实任务质量公开榜单与课程自建评测互补S09、L5
K-DEPLOY推理与部署把模型/API 接成可访问的服务网站托管、模型推理、训练是三种资源需求L2、S10
K-CARD数据卡与模型卡记录来源、用途、版本、限制和责任边界帮助他人判断是否适合复用L3
