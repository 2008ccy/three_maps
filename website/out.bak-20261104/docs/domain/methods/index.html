在地图中的位置：训练与适配

路线解决什么与其他路线的关系什么时候采用与主要局限
提示与上下文示例说明任务、格式和回答边界是低成本基线，也能与其他方案组合先试；不能仅靠提示补齐缺失知识
RAG按问题提供可更新的外部资料与微调互补；与长上下文部分替代需要引用、课程知识经常变化时优先试；依赖检索质量
SFT学习示范回答的行为模式依赖已有模型和样本；可用全参或 LoRA 实现格式和引导方式持续不合适时考虑；存在过拟合和能力回退
LoRA/QLoRA在受限资源下实现模型适配是 SFT 等训练的参数/显存方案，不与 SFT 平级互斥有可用设备和合格样本时再做；兼容性、序列长度影响资源
全参数微调更新全部模型参数与 LoRA 是不同的适配方案可作比较背景；本组缺乏资源时不强行执行
偏好优化调整偏好、回答行为通常在已有模型与数据基础上进一步开展自主拓展；不作为第一版依赖
蒸馏与推理量化降低推理资源需求可与已适配模型协同使用确实需要自托管推理时评估；要重新测质量
工具调用/Agent获取信息或执行动作可与 RAG 组合只有问答需要行动时才加，需处理权限与错误传播

本组路线判断： 先用授权资料和 API 完成可引用问答；若错误来自找不到资料，先改解析、切块和检索；若资料已找对但输出行为持续不符合要求，再评估 LoRA。是否“微调优于 RAG”不能脱离任务、数据与预算作绝对判断。[分析判断；S02—S06]
