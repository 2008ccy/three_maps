在地图中的位置：数据与评测

数据

第一批数据用经授权的课程讲义、教学大纲、教材节选及人工核对的问答。每份资料记录作者、许可/使用范围、章节、时间、版本和来源链接；不将完整受限课件直接公开。Common Crawl、The Pile 等只作为预训练背景，不是完成本次作业必须下载的数据。

评测

建议从 30 道真实问题起步，再扩展到 50—100 道。这是项目建议数量，不是作业指定指标。题目至少覆盖概念解释、关系比较、资料定位、无答案和模糊问题；训练、调参与最终测试分开。评价时同时记录：

维度操作定义记录方式
答案正确性按预先写好的要点，是否正确且不遗漏关键条件每题 0/1/2 分并记录判分理由
引用支持率所引用的片段是否确实支持对应结论支持的引用数/检查的引用数，同时给出分子分母
检索表现标注的支持片段是否进入前 k 条结果记录 k、命中题数和总题数
无答案处理无依据时是否恰当拒答或要求补充单列无答案题的结果，检查过度拒答
使用体验同学是否能理解，并找到原文和后续入口独立试用记录与具体问题
时延和成本端到端耗时、输入输出 token 和费用小样本报逐条数据/中位数；量足够后再看 P95

不要为了凑指标使用无来源的“90%准确率”或“4秒内完成”；先跑基线，再确定本组目标。自动模型评分可以辅助归类，评分规则和抽样人工复核仍由小组负责。

资源

网页交互、内容整理和调用模型 API 可用普通笔记本开发。公开网站用托管平台；AI 推理由提供方执行，本组按使用付费。训练实验另用可获得的学校 GPU 或短租 GPU，先小模型、小样本、小批量试跑。不能用“7B 权重约占若干 GB”代替整套训练显存估计，序列长度、激活、优化器和运行框架都会影响峰值。[L2、S04]
