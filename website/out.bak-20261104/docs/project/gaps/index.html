最终验收清单

  • 选题、边界、目标课程和成长方向已由成员确认。
  • 三张地图有实际内容，重要节点和关系可跨图查询，事实/观点/推断分清。
  • 本校课程与培养方案有依据，理解程度经过本人确认。
  • 生态解释至少一至两条具体关系，版本和会议目录标清。
  • 三种分析方法各有本组实际分析过程，课堂第三个观名称已核对。
  • 有实际成长习惯记录和经成员确认的真实认识修正。
  • 一项地图AI可用，回答可追溯，访客不用个人密钥。
  • 中期起网站在云端公开运行，国内普通网络可访问。
  • 每周至少检查一次，重要修改有日期、依据、原因和负责人。
  • 至少三名非组员独立反馈已核实并记录处理理由。
  • 期末仍可访问，成员贡献、局限和后续学习入口可见。
