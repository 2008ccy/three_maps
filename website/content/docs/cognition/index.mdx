- 三个观：从结构、变化与证据选择检查角度。
- 分析方法：在损失、榜单、成本三个案例中直接运用方法。
- 成长习惯：记录任务与证据，试验复验，独立反馈与复盘。
- 认识修正：原判断、新证据、新结论与下一步。

指导与反馈方向沿用原材料；方法已融入案例，不再单独钻取。教学推演与真实实践分别记录。
