## 浙江大学 2026 级人工智能专业：课程怎么串起来

来源：[新版讲解稿 L6](ref:L6) 第 12 页第 07 节。讲解稿说明本节按《2026 级人工智能专业培养方案》整理。下面保留讲解稿的课程名称、阶段分组、作用说明和标签；具体选课与学期以教务系统为准。当前尚未对照正式培养方案原件及课程大纲独立核验。

课程主线：**数理基础 → 编程与系统 → AI 核心 → 方向课 → 科研实践**。下表仅列讲解稿选取的、与模型构建最相关的课程，不是完整培养方案，也不补入原稿未列出的学分、课程编号或学时。

| 阶段 | 课程 | 在模型构建里干什么 | 标签 |
| --- | --- | --- | --- |
| 大一 | 微积分（甲）I/II、线性代数（甲） | 看懂损失、梯度、矩阵运算 | 前置基础 |
| 大一 | 智能程序设计、人工智能前沿与创新（新生研讨课） | 会写代码；建立领域全景 | 前置基础 |
| 大二 | 离散数学及其应用、高级数据结构与算法分析 | 复杂度、图、搜索、工程基础 | 前置基础 |
| 大二 | 概率论与数理统计 | 分布、估计、评测置信 | 前置基础 |
| 大二 | 人工智能引论、深度学习导论 | 建立 AI/深度学习主框架 | 核心覆盖 |
| 大二 | 计算机系统 I/II、人工智能芯片与系统 | 内存、并行、推理部署 | 部分涉及 |
| 大二 | 人工智能前沿实践 | 把知识变成动手经验 | 实践应用 |

| 大三 | 人工智能伦理与安全 | 偏见、隐私、安全、责任 | 部分涉及 |

**不要按课名猜内容。**“机器学习”和“高级机器学习”可能有不同的深度，“人工智能引论”在不同年份也会调整。选课前看课程大纲、问任课老师；不确定的标“待核实”。未来专业课程是后续学习入口，不应当作本课程的先修要求。

## 一条最小学习路线

来源：[新版讲解稿 L6](ref:L6) 第 12 页第 7.1 节。先入门，不必一次选满方向课。

1. **大一：**微积分、线代、智能程序设计；把 Python 和矩阵运算用熟。
2. **大二：**概率统计、人工智能引论、深度学习导论；手写一个小 MLP，跑通训练/评测。
3. **大三：**高级机器学习 + 一门方向课（NLP 或 CV）+ 科研实践；做一个完整项目。
4. **大四：**科研实践/毕设；把项目做成可复现、可展示的作品。

## 三条发展路径

来源：[新版讲解稿 L6](ref:L6) 第 13 页第 8.1 节。三条路径代表关注问题与能力目标，不是三个固定的“人设”。

| 路径 | 关注的问题 | 讲解稿建议的课程方向 | 能力目标 |
| --- | --- | --- | --- |
| 科研型 | 为什么有效 | 高级机器学习、方向课、科研实践 | 能复现论文、能做消融、能写清楚失败原因 |
| 工程型 | 怎么稳定跑起来 | 计算机系统、人工智能芯片与系统、科研实践 | 能训练、能部署、能压测、能回滚 |
| 设计/产品型 | 人怎么用 | 人工智能伦理与安全、认知神经科学导论、智能产品设计（方向课） | 能访谈、能做原型、能评估体验 |

## 三个作品，证明三种能力

- **经典基线项目：**证明会做 baseline、懂评估。
- **微调/从零小模型项目：**证明理解模型内部。
- **RAG/领域助手项目：**证明能把模型变成系统。

每个项目用“问题 → 约束 → 方案 → 评测 → 失败 → 反思”六段式讲清楚。课程给工具和语言，项目给手感和判断；每学一门课，至少做一个小项目。以上为讲解稿建议，不是团队已经完成的实践记录。

## 自主拓展入口

- [Stanford CS224N](https://web.stanford.edu/class/cs224n/)：神经网络与自然语言处理的系统学习入口；具体以所选年度公开资料为准。[S13](ref:S13)
- [Stanford CS336](https://cs336.stanford.edu/)：覆盖从数据处理到语言模型构建、训练与评测，要求较强 Python、深度学习和系统基础，适合作为后续路线，不宜让大一同学先完整学完才能做地图。[S12](ref:S12)
- [PyTorch Tutorials](https://docs.pytorch.org/tutorials/) 与 [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1)：按当前卡住的任务选学；能解释和复现一个小例子后再扩展。

本次课程交付仍按七周作业安排；四年培养路径和素材中的十二周实验计划用于后续学习，不是本次作业的先修门槛。
