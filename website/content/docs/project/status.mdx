## 第一版提供什么

三张地图的分层页面、核心条目详情、来源目录、跨图链接、中文搜索、更新记录和待核实清单。浏览无需登录。

## 下一阶段

| 项目 | 当前状态 | 后续条件 |
| --- | --- | --- |
| 用户登录、地图下反馈 | 按本轮选择暂缓 | 后续可选 GitHub 评论或认证与数据服务 |
| 地图 AI 问答 | 尚未接入 | 需要服务端保管模型密钥、预算限制与可回溯引用 |
| Open 风格首页 | 留到后续视觉阶段 | 在保留文档结构的基础上单独设计 |
| 学校课程、课堂原文、实验记录 | 待补证 | 由成员补真实材料，不能用示例代替 |
| 公开上线与国内网络访问 | 待实际部署与验证 | 本地可访问或构建通过不等于公开上线 |

GitHub Pages 可以托管本版静态页面与浏览器交互，不能独立运行需要服务端密钥的 AI 接口。[S15](ref:S15)、[S16](ref:S16)。

## 与课程作业的关系

作业仍要求至少一项可用的地图 AI、真实分析记录、持续更新以及至少三名非组员反馈。第一版只是阶段交付，不能将这些未完成项勾选为完成。
