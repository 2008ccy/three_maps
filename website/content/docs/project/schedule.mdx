| 作业阶段 | 内容与工作 | 可检查的产物 |
| --- | --- | --- |
| 第1周 | 定课程、边界、成员分工与预算；核对课堂原文 | 任务卡、角色分工、待核实清单 |
| 第2周 | 核实核心概念、工具、真实课程和来源 | 领域图与一条完整关系链 |
| 第3周 | 生态关系、认知案例与网站最小版；提前测域名与网络 | 三图内容、可用公开地址、问题记录 |
| 第4周中期 | 展示三图、跨图和真实AI；说明未知与修改计划 | 公开网址、AI演示、外部访问记录 |
| 第5周 | 获取至少三名非组员独立反馈，逐项核实 | 反馈、采纳/保留理由与修改记录 |
| 第6周 | 深化实际分析、成长习惯与认识修正 | 案例证据、前后变化、再次访问验证 |
| 第7周期末 | 检查持续可访问、成员贡献、局限与后续学习 | 完整网站、来源、周记录、展示材料 |

以上沿用作业阶段编号，不能根据今天日期猜测小组已经进入哪周；具体截止日期以教师通知为准。每周记录“本周完成、发现的问题、下周动作、负责人”，没有变化也保留检查结果。
