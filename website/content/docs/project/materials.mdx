2. 将概念、工具、课程、团队与分析案例接到共同任务，而非依次粘贴三份素材。
3. 保留L4的分层与个人运行自述，去除星数/最新版本的排名意义；不把仓库推送时间或一次下载失败当作行业兴衰证据。

6. 用作业的三类理解标签呈现状态，不把L3的扩展等级、目标等级或“资料可支撑”等同于本组掌握程度。
