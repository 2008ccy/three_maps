## 先维护正在使用的依赖

| 入口 | 主要回答什么 | 核对动作 |
| --- | --- | --- |
| 模型卡与发布说明 | 采用的对象、版本和条件 | 对应实际模型与渠道 |
| 官方文档 | 接口、配置和支持范围 | 对应安装或服务版本 |
| 发布记录 | 发生了哪些变化 | 判断是否需要升级并复测 |
| 论文 | 方法来处与实验条件 | 区分原实验和课程验证 |
| Issue、讨论与博客 | 可能的故障线索 | 带着日期和环境回查并复现 |
