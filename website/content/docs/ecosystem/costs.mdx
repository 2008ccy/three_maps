## 两种运行路线

| 路线 | 运行方 | 项目需要承担 |
| --- | --- | --- |
| 自托管 | 本组或受托运维者 | 设备、环境、服务容量、故障与升级 |
| 托管 API | 供应方 | 服务选型、网络、调用用量、异常与预算 |

运行工具入口见 [S10](ref:S10)、[S27](ref:S27)、[S28](ref:S28)，费用按实际服务条件核对，参考入口见 [S21](ref:S21)。

## 把成本按责任分列

模型发布方投入研发与训练，平台承担分发，贡献者维护工具；项目还承担网站、推理、资料核实和持续修订。记录一次性投入、持续用量与人工工作，未知金额留待实际核对。[L8](ref:L8)

## 一条维护记录

`问题与时间｜证据和版本｜核实原因｜修改者与复核者｜修订动作｜固定问题复测｜剩余问题`

读者反馈先核实，再决定改资料、检索、提示或界面。真实意见与教学示例分别记录。
