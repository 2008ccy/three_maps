| 环节 | 谁承担资源 | 在本组项目中的表现 | 不能据此推出什么 |
| --- | --- | --- | --- |
| 模型预训练/发布 | 模型机构及其资源提供方 | 本组复用已有模型或 API | 没有公开账单就不能写单次训练必为多少美元 |
| 权重分发 | 平台、发布者、镜像维护者等 | 下载渠道与带宽可用性会影响实验 | 免费下载不等于平台无成本或长期免费 |
| 工具维护 | 社区贡献者、公司和研究者 | 提供适配、文档与 bug 修复 | 热度不等于对本任务的适配质量 |
| 推理 | API 调用方或自托管者 | 小组为公开 AI 调用设置预算 | 开放权重不意味着推理免费 |
| 内容和应用 | 组员、资料权利人和网站运营者 | 资料整理、核实、托管和维护 | 使用模型 API 不能替代小组责任 |
| 访客使用 | 同学提供真实问题和反馈 | 浏览与问答不索取个人模型密钥 | 不默认同学愿意上传个人资料 |

本项目是课程学习服务，先由小组/课程可用资源承担托管和 API 费用，让同学免费使用。若成为长期产品，需另外评估学校或组织是否愿意为维护、访问量和服务质量付费；当前不虚构商业收入。

国际合作与竞争在这里体现为论文与权重跨机构传播、工具兼容，以及模型许可、分发渠道和服务地域造成的可获得性差异。**一次网络超时不能证明整个地区不可访问，某个仓库更新较少也不足以证明某模型系列衰退。** [L4](ref:L4) 的“Llama 相对衰退”保留为待检验假设，不列为本稿已证实结论。
