# 更明显、更舒缓的像素帷幕与返回首页

- `pixel-roundtrip.gif`：最终页面的真实鼠标截图序列，先首页进入领域，再点击领域面包屑返回首页，两次实际操作拼接展示。源图 `forward-*.png`、`back-*.png` 均为 1440×900，动图缩至 960×600；时间见各自 frame-times.json，首尾及两段衔接增加展示停留。不代表实际网页帧率，循环回首帧仅为演示行为。
- `pixel-return-home.gif`：只展示实际返回首页过程。
- `pixel-return-mobile.gif`：390×844 下实际从生态地图返回首页，保留原尺寸。
- 手工验证浏览器尺寸、导航、焦点、返回状态及无残留画布。临时服务模拟 Canvas 失败、减少动态效果、sessionStorage 不可访问；不更改系统设置、不进入生产导出。
- 本轮返回转场作用于地图中的首页链接（包括面包屑和站点标识）；浏览器工具栏历史前进/后退保持原生行为。
