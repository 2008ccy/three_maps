# 三张活地图 · 模型构建

围绕“**从预训练模型到领域助手——语言模型的数据、微调、评测与部署**”开展课程项目。

典型任务：研究怎样把一个开源语言模型适配为课程答疑助手，以领域、生态、认知三张相互关联的地图呈现知识、参与者与分析过程。

已确定“模型构建”选题，目前处于资料准备与方案规划阶段，正式成果为作业要求整理和建设计划。

## 拟定技术与上线方式

- 前后端：Next.js、TypeScript；地图展示：Cytoscape.js。
- 数据：SQLite 与 Prisma；AI 问答由服务端调用模型 API。
- GitHub 管理源码及版本，云服务器通过 Docker Compose 运行网站，Caddy 提供 HTTPS。
- 中期起公开访问；浏览无需登录，访客无需提供模型密钥；上线前用国内普通网络和非组员设备验证。

具体实施顺序、生产配置及验收方法见建设计划第 4 节。此处为技术规划，不是当前项目的启动说明。
