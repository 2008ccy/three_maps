# 反馈接入准备验证 · 2026-11-04

本次完善现有公开反馈功能。没有连接或创建真实云资源，没有将验证内容写入线上数据库，也没有发布网站。

## 验证范围

- 默认未接通构建：表单可预览，提交禁用；带入 RAG 对象，字段错误聚焦正确，HTML 输入按文本显示；390px 手机无横向溢出。
- 已配置接口、`/three_maps` 子路径构建：浏览器请求拦截到真实后端业务处理器，数据只保存在测试进程数据库 fixture；不使用真实云端或浏览器本地存储。
- 模拟首个 POST 网络失败，保留表单内容，重试复用幂等键；服务端仅生成一条记录。
- 列表原先筛选另一张地图和“已完成”，提交新反馈后正确进入新编号详情。
- 测试管理员更新回复和状态后刷新可见；429倒计时结束前禁用提交；无效编号不向接口发请求。
- 两种构建均运行静态导出链接检查；完整网站及后端测试覆盖协议、字段越权、事务幂等、限频、隐藏记录、公开字段投影与分页。
- PostgreSQL 使用 PGlite 的真实 PG 引擎测试初始化 SQL、索引、RLS、最小权限角色和事务回滚。单连接测试不代表实际云端多连接并发、网关、TLS及跨设备验收已完成。
